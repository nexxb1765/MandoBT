# Mando BT

Convierte tu teléfono Android (9 o superior) en mando, teclado y mouse Bluetooth
para controlar una PC u otro teléfono.

## Compilar el APK
1. Instala Android Studio y abre esta carpeta (File > Open).
2. Espera a que termine la sincronización de Gradle.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. El APK queda en app/build/outputs/apk/debug/app-debug.apk
5. Cópialo al teléfono e instálalo (permitir "orígenes desconocidos").

## Usar
1. Abre la app y acepta los permisos de Bluetooth.
2. Toca "Visible" y, en la PC/otro teléfono, empareja con tu teléfono.
3. Toca "Conectar" y elige el dispositivo. Después reconecta solo.
